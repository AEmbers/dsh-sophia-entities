# 01 — 多页面加载不再被更新订阅阻塞

**What to build:** 同一 Host 的多个 Team 页面能够同时加载成员、频道和 Thread，并收到更新；通知不再长时间占用普通 HTTP 请求连接。使用 Harness 现有流式 Remote，从 Host 通知到 Client 展示完成一条可验证路径，不限制唯一活跃页面。
**Blocked by:** None — can start immediately；已获实施授权。
**Status:** complete — 已实施、独立验收并合并进 master（PR #25 → `d7007d3`；验收基线 `796ccba`）。未勾选项经 Human 2026-09-17 指示**明确关闭**（不随本工作项交付，未另立工作项），清单见工作项 README 的「明确关闭的残余」。

- [x] 同一改动更新 Host 声明、生成接口、Client 消费和所需测试；删除旧长轮询及其超时、重试路径，不保留静默兼容回退。

## 范围限制

本任务修复传输阻塞，不宣称解决草稿跨页覆盖、导航恢复、跨页私有已读同步或隐藏页自动已读。它们有独立的正确性评估入口，不能因本任务通过就忽略。后台节流和跨页连接共享不在本任务内。

## 验证入口

从工作项的诊断材料定位现有 Host scope、Client 订阅和真实 Web 测试。首个断言必须经过浏览器真实网络与生成 Remote；只测 mock 异步流无法证明连接占用问题消失。
